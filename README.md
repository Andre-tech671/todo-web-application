# Todo App

A simple and intuitive Todo application built with HTML, CSS, and JavaScript. This app allows users to manage their daily tasks efficiently with features like adding, completing, deleting tasks, and filtering them by status.

## Features

- **Add Tasks**: Easily add new tasks by typing in the input field and clicking the add button or pressing Enter.
- **Mark as Complete**: Check off tasks when completed.
- **Delete Tasks**: Remove individual tasks using the delete button.
- **Filter Tasks**: View all tasks, only active tasks, or only completed tasks.
- **Clear Completed**: Remove all completed tasks at once.
- **Task Counter**: Displays the number of remaining active tasks.
- **Date Display**: Shows the current date in the header.
- **Persistent Storage**: Tasks are saved in the browser's local storage, so they persist across sessions.
- **Responsive Design**: Works well on different screen sizes.
- **Empty State**: Shows a friendly message when there are no tasks.

## Technologies Used

- **HTML5**: Structure of the application.
- **CSS3**: Styling and responsive design.
- **JavaScript (ES6+)**: Functionality and interactivity.
- **Font Awesome**: Icons for better UI.
- **Local Storage**: For data persistence.

## How to Run

1. Clone or download the project files.
2. Open `index.html` in your web browser.
3. Start adding your tasks!

No server or additional setup is required as this is a client-side application.

## Usage

- Enter a task in the input field and click the "+" button or press Enter to add it.
- Click the checkbox next to a task to mark it as completed.
- Click the "x" button to delete a task.
- Use the filter buttons (All, Active, Completed) to view specific tasks.
- Click "Clear completed" to remove all finished tasks.
- Your tasks will be saved automatically and persist when you reload the page.

## Browser Support

This app works in all modern web browsers that support ES6 JavaScript and local storage.
